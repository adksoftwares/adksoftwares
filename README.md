## 🚀 Active Showcase Systems

Here is a unified catalog of the production-ready systems I have developed:

### [1. 🍳 Kitchen Display System (KDS)](https://github.com/adksoftwares/KDS)
*A real-time, high-volume restaurant order synchronization ecosystem connecting customer tables to the kitchen.*
- **Features:** Jetpack Compose tablet client, non-blocking low-latency `SoundPool` chiming alerts, always-on screen locks, anonymous session handshakes, and full Firestore offline caching.
- **Tech:** Kotlin, Jetpack Compose, React, Vite, Firebase Firestore & Auth.
- 🔗 **View Repository:** [github.com/adksoftwares/KDS](https://github.com/adksoftwares/KDS)

### [2. 💳 Point of Sale System (POS)](https://github.com/adksoftwares/POS-System)
*An enterprise desktop and mobile cashier POS network.*
- **Features:** Standalone Electron cashier desktop wrapper, native hardware thermal printing triggers, mobile tables seating grid, and background inventory deductor Cloud Functions.
- **Tech:** React, Electron, Firebase Functions, Vite, Android Client.
- 🔗 **View Repository:** [github.com/adksoftwares/POS-System](https://github.com/adksoftwares/POS-System)

### [3. 🐍 Relational Restaurant Server](https://github.com/adksoftwares/Food-Restaurant)
*An offline-first backend local server and relational database manager.*
- **Features:** Local Python asynchronous server engine, auto-seeding mock schemas, static control panels, and automated PyInstaller build compilation scripts.
- **Tech:** Python, SQLite, PyInstaller.
- 🔗 **View Repository:** [github.com/adksoftwares/Food-Restaurant](https://github.com/adksoftwares/Food-Restaurant)

### [4. ⚡ Asynchronous FastAPI Microservice](https://github.com/adksoftwares/FastAPI-Gig)
*A modern, containerized, and documented REST API boilerplate.*
- **Features:** Uvicorn ASGI asynchronous request pipelines, strict Pydantic model payload validations, dynamic Swagger OpenAPI auto-docs, and secure multi-stage Docker builds.
- **Tech:** FastAPI, Pydantic, Docker, Python.
- 🔗 **View Repository:** [github.com/adksoftwares/FastAPI-Gig](https://github.com/adksoftwares/FastAPI-Gig)

### [5. 📱 Native Android App](https://github.com/adksoftwares/Android-App)
*A native Android mobile application showcasing elite design guidelines.*
- **Features:** Modern declarative Jetpack Compose UI, non-blocking Kotlin Coroutines background threading, cold & hot StateFlow streams, clean MVVM data separation, and Gradle Kotlin DSL build setups.
- **Tech:** Kotlin, Android SDK, Jetpack Compose, Kotlin DSL.
- 🔗 **View Repository:** [github.com/adksoftwares/Android-App](https://github.com/adksoftwares/Android-App)
